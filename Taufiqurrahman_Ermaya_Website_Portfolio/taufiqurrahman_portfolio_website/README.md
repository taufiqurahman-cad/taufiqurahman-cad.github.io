# Taufiqurrahman Ermaya — Portfolio Website

A responsive, English-language personal portfolio website built with plain HTML, CSS, and JavaScript.

## Preview locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. Keep the `assets` folder and both PDF files in the same folder as `index.html`.

For a local development server, you can run:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.

## Publish with GitHub Pages
1. Create a public repository on GitHub.
2. Upload all files and folders from this package (not only `index.html`).
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the website. The public URL will appear in the Pages settings.

## Included
